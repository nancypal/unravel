# unravel

Randomized Ravelry project preview for any pattern.

Search for a knitting pattern (or click one of the popular examples) and see 8 random finished-project photos from Ravelry, so you can get a feel for how a pattern looks on real people before you cast on. Hit refresh for 8 more.

**Live site:** https://unravel-6d6m.onrender.com/

## Built with

Node.js, Express and the [Ravelry API](https://www.ravelry.com/api). The front end is a single `index.html`.
